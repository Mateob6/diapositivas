# Diapositivas

Diapositivas web de las clases de Mateo Belalcazar, hechas con un motor propio (HTML, CSS y GSAP).

Cada clase está en su carpeta y funciona sin internet: se abre su `index.html`. Se avanza con las flechas, el espacio, un clic o un clicker; F pone pantalla completa.

Sitio: https://mateob6.github.io/diapositivas/
