# Diapositivas

Diapositivas web de las clases de Mateo Belalcazar, hechas con un motor propio (HTML, CSS y GSAP).

Las clases se listan por curso y unidad en **https://mateob6.github.io/materials**, donde cada una se puede ver en el navegador o bajar en PDF. Cada clase vive en `curso/unidad/clase/` y se reemplaza en la misma dirección cuando se actualiza.

Se avanza con las flechas, el espacio, un clic o un clicker; F pone pantalla completa. En la portada hay un botón de modo oscuro.
